# tenders.best — лендинг

Премиальная посадочная страница платформы для тендеров и закупок **tenders.best**.
Статический сайт без сборки: чистый HTML, CSS и JavaScript.

## Структура

```
index.html                 — разметка всех секций (спрайт SVG-иконок внутри)
assets/css/styles.css      — дизайн-система, компоненты, анимации, адаптив
assets/css/fonts.css       — @font-face (Inter, Manrope — локально, SIL OFL)
assets/js/main.js          — навигация, reveal-анимации, счётчики, табы, слайдер, параллакс
assets/img/logo-mark.png   — иконка логотипа (вырезана из официального логотипа)
assets/img/hero-person.webp — фото специалиста для hero (вырезано из референса, фон удалён)
assets/img/favicon.png, apple-touch-icon.png
assets/fonts/              — woff2-субсеты (latin, latin-ext, cyrillic, cyrillic-ext)
```

## Запуск

Откройте `index.html` в браузере или поднимите любой статический сервер:

```bash
npx http-server -p 8080 .
```

## Секции

1. Hero — заголовок, CTA, ноутбук с дашбордом тендеров, фото специалиста и 7 бейджей
2. «Платформа работает на результат» — 6 табов с отдельными мини-интерфейсами
3. «Почему выбирают tenders.best» — градиентный блок с 4 преимуществами
4. Три карточки решений — аналитика, документы, автоматизация (орбита процессов)
5. «Три шага до победы» — сцена приложения + нумерованные шаги
6. Отзывы — ручной слайдер с карточкой результата и полосой клиентов
7. Футер — колонки ссылок, подписка, крупный CTA

## Замена фото

Специалист в hero — `assets/img/hero-person.webp` (PNG/WebP с прозрачным фоном,
768×872). Чтобы поставить другое фото, замените файл или `src` у `<img>` внутри
`.hero__person` в `index.html`; размер задаётся классом `.hero__person`.

## Анимации

Сдержанные: короткий fade-up при скролле, счётчики KPI, рост столбцов и отрисовка
графиков один раз при появлении, переключение табов, слайдер отзывов.
Бейджи в hero статичны и слегка «плавают» только при наведении на блок с фото.
Шапка скрывается при прокрутке вниз и появляется при прокрутке вверх.
Учитывается `prefers-reduced-motion`.
