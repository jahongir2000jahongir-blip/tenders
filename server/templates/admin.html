Как работает обновление

Сбор запускается автоматически каждые ч. Дубликаты отсекаются по паре «источник + номер» и по отпечатку содержимого (страна, название, дедлайн, заказчик). Для запуска из cron: 0 */3 * * * cd /path/to/tenders && .venv/bin/python -m server.collect и переменная TB_SCHEDULER=0 у веб-сервера.
